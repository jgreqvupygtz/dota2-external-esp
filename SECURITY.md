# Security Policy

## Educational use only

`dota2-external-esp` is published **for educational and research purposes only**.
Using external cheats in live Dota 2 matches violates the Steam Subscriber
Agreement and will result in VAC / permanent bans. The maintainers do not
condone or support cheating in online play.

## Reporting

If you find a vulnerability in this *tooling* (e.g. unsafe memory read,
arbitrary file write in the offset loader), open a private security advisory
or email `sec@dota2-external-esp.dev`. Please do not file public issues for
sensitive reports.

## What is out of scope

- Requests for working anti-cheat bypasses
- Requests to target specific players or accounts
- Distribution of compiled binaries

## Supported versions

Only the latest `main` branch is supported with fixes.
